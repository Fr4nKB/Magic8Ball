# 🎱 Magic 8 Ball – Glyph Toy 🎱
**Magic 8 Ball Glyph Toy** is one of the **first community-crafted** experiences for the **Nothing Phone (3)**, reimagining the nostalgic charm of the iconic 1990s Magic 8 Ball.

This repository contains the source code for the **Magic 8 Ball Glyph Toy** Android app, available on  <a href="https://play.google.com/store/apps/details?id=com.frank.magic8ball">Google Play</a>.
